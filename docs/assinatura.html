Política de assinatura e privacidade

Última atualização: 28 de outubro de 2026

Assinatura de código

Assinatura de código gratuita fornecida pela SignPath.io, com certificado da SignPath Foundation.

Situação atual: inscrição em andamento. Até a primeira versão assinada, os instaladores do Telinha não têm assinatura digital.

Só são assinados os arquivos produzidos a partir do código-fonte público do Telinha, compilados automaticamente pelo GitHub Actions a partir de uma tag de versão. Nenhum arquivo compilado em computador pessoal é assinado.

Papéis no projeto

PapelQuemO que faz
Autor e revisor (committer / reviewer)Jonatan FragosoEscreve e revisa todo o código que entra no repositório.
Aprovador (approver)Jonatan FragosoAprova manualmente cada pedido de assinatura de uma versão.

Contribuições de outras pessoas só entram depois de revisadas pelo autor. As contas usadas no GitHub e na SignPath têm autenticação em dois fatores.

Privacidade

O Telinha não tem servidor próprio, não exige conta e não coleta estatísticas de uso (telemetria). Ele só se comunica pela rede nos casos abaixo:

Com quemQuandoO que é enviado
Outros PCs com o Telinha na sua rede do TailscaleEnquanto o app está abertoSeu apelido, sala, se está transmitindo e, se você ligar a opção, o nome do jogo que está jogando. Também a tela, o áudio e as mensagens de chat que você decidir enviar. Tela e áudio vão direto de PC para PC; chat e sinais de conexão passam pelo PC do host, que também é um dos PCs da sala. Nada sai da rede criptografada do Tailscale.
GitHub (github.com)Ao abrir o app e a cada 2 horasUma consulta para saber se existe versão nova e, se existir, o download dela. O GitHub vê o seu endereço IP, como em qualquer download.
Discord (discord.com)Só se você ligar "Mostrar quando estou jogando", no máximo uma vez a cada 7 diasO download da lista pública de jogos que o Discord reconhece. Nada sobre você é enviado; o Discord vê o seu endereço IP.
  • O app consulta o programa do Tailscale no próprio PC (tailscale status) para descobrir os outros PCs da rede.
  • Com a detecção de jogo ligada, a lista de programas abertos é lida a cada 15 segundos e não sai do seu PC. Só o nome do jogo reconhecido é mostrado para a sala.
  • As configurações ficam só no seu PC, em %APPDATA%\Telinha. As mensagens de chat não são gravadas em lugar nenhum.
  • Nada é transmitido sem você escolher a tela e confirmar.
  • Esta página e a página de download consultam a API pública do GitHub para mostrar as versões disponíveis.

Code signing policy and privacy

Last updated: October 28, 2026

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Current status: application in progress. Until the first signed release, Telinha installers are not digitally signed.

Only files built from Telinha's public source code are signed. They are built automatically by GitHub Actions from a version tag; nothing built on a personal computer is signed.

Team roles and their members

RoleMemberResponsibility
Committer and reviewerJonatan FragosoWrites and reviews all code merged into the repository.
ApproverJonatan FragosoManually approves each signing request for a release.

External contributions are merged only after review by the maintainer. The GitHub and SignPath accounts involved use multi-factor authentication.

Privacy policy

Telinha has no server of its own, requires no account and collects no usage statistics (telemetry). It only transfers information over the network in the cases below:

WithWhenWhat is sent
Other computers running Telinha on the user's Tailscale networkWhile the app is openThe user's nickname, room, streaming status and, if the user enables it, the name of the game being played; plus the screen, audio and chat messages the user chooses to send. Screen and audio go directly from computer to computer; chat and connection signaling are relayed by the host, which is also one of the computers in the room. Nothing leaves Tailscale's encrypted network.
GitHub (github.com)On start and every 2 hoursA request to check for a new version and, if there is one, its download. GitHub sees the user's IP address, as with any download.
Discord (discord.com)Only if the user enables "show when I'm playing", at most once every 7 daysDownload of Discord's public list of detectable games. Nothing about the user is sent; Discord sees the user's IP address.
  • The app queries the local Tailscale client (tailscale status) to find other computers on the network.
  • With game detection enabled, the list of running programs is read every 15 seconds and never leaves the computer. Only the recognized game's name is shown to the room.
  • Settings are stored only on the user's computer, in %APPDATA%\Telinha. Chat messages are not stored anywhere.
  • Nothing is streamed unless the user picks a screen and confirms.
  • This website and the download page query GitHub's public API to list the available versions.
